    Design

    Write path

    1. Route. Any node accepts the connection; followers reply MOVED with the leader's address.
    2. Append. The leader timestamps the command and appends it to the Raft log.
    3. Replicate. Followers write the entry to a checksummed WAL and fsync; one fsync covers a batch.
    4. Commit. Once a majority acknowledges, the entry is committed and applied on every replica.
    5. Reply. The client receives the result. Reads use ReadIndex and are linearizable.
